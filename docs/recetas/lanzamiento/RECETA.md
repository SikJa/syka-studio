# Receta de fábrica: lanzamiento de producto

Un film corto (15–40 s) que presenta un producto o una función con su UI real:
gancho, presentación, demo, resultado y cierre con logo.

Se usa con `syka_receta action:usar slug:lanzamiento`. Después, `syka_plan`
lleva el video fase por fase:

1. **Brief**: la idea, el producto, antes y después, el cierre y el canal.
2. **Tres historias** distintas para elegir (recurso y forma diferentes). Si la
   persona dijo que no preguntes, se elige la recomendada.
3. **Escenas**: frase de hasta 6 palabras, imagen, planos con destino, costura,
   assets y música con sus golpes medidos.
4. **Storyboard**, solo si está activado.
5. **Construir y gate**: la entrega se marca lista solo con el plan completo y
   un gate aprobado sobre la versión final.

Las reglas completas (estilo, sonido, ritmo y controles) están en
`receta.json`. Para tu propia versión, copiala con otro nombre: las recetas de
fábrica no se modifican.
