# Plantilla opcional de dirección visual

Guardá una versión concreta en el proyecto como `frame.md`. No dejes campos sin resolver como si fueran decisiones aprobadas.

```yaml
format: 9:16
resolution: [1080, 1920]
colors:
  background: '#101218'
  text: '#f5f5f5'
  accent: '#70cbb1'
typography:
  display: 'fuente realmente disponible'
  body: 'fuente realmente disponible'
layout:
  safeInset: 'según contenido y plataforma de destino'
motion:
  character: 'rápido, preciso, con pausas de lectura'
  continuity: 'conservar la tarjeta y transformar sus datos'
```

Anotá debajo objetivo, contenido exacto, assets/rutas reales y referencias con sus intervalos. Una tabla de beats puede llevar inicio/fin, qué demuestra, qué aparece, movimiento y sonido. Indicá qué se conserva y qué se puede cambiar. Enlazá este archivo y los componentes desde la receta. Los tamaños de fuente, duraciones y márgenes se resuelven sobre el texto y footage reales.

Para motion amplio, agregá qué debe entender el espectador, estado de entrada/salida, ancla persistente, intervalo de lectura estable y tiempo de riesgo para revisar. Conservá por formato su layout real. Referí `design.md` y las imágenes revisadas de `syka_motion_review` en la receta; no anotes aprobación estética si sólo pasaron checks técnicos.
