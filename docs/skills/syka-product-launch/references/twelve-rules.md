# Doce criterios editoriales para lanzamientos

Adaptación original del artículo de Amanda Sartini del 10/10/2026:
https://x.com/i/article/2109015312729587712

| Criterio | Planificar | Evidencia al revisar |
|---|---|---|
| 1. Producto protagonista | Escenario tranquilo, negro si corresponde a la marca | UI distinguible del fondo a tamaño de destino |
| 2. Capítulos útiles | Numerar cuando orienta, asignar tiempo según complejidad | Puede seguirse la progresión sin leer una lista excesiva |
| 3. Acción y resultado | Disparador → reacción → resultado con fuente real | Cursor/entrada y cambio de estado reconocibles |
| 4. Lectura sin audio | Titular, apoyo, holds y jerarquía | La pieza se entiende al verla en mute |
| 5. Apertura útil | Producto y promesa presentes desde el cuadro inicial | Inspeccionar el primer cuadro del archivo real y su poster |
| 6. Cámara con propósito | Foco y pausa, resolución suficiente | Sin perder orientación ni emborronar detalles al acercar |
| 7. Callout preciso | Bounds medidos del control, escala y recorte | La señal sigue apuntando al control correcto |
| 8. Música/voz y acciones | Toma/pista elegidas, palabras y ataques medidos | Escucha y cuadro vecino confirman sincronización |
| 9. Contraste narrativo | Escala/luz/densidad/escena oscura como opción | Cambio con propósito, foco estable en lectura |
| 10. Cierre verdadero | Producto, marca y CTA según disponibilidad real | Texto final legible, CTA respaldado |
| 11. Destinos resueltos | Variantes elegidas con composición propia | Lectura y encuadre comprobados por separado |
| 12. Demo auténtica | Datos preparados, función verificable | Evidencia distingue producto real, prototipo y plan |

La capa visual puede mantenerse activa: luz que recorre vidrio, respiración del
orbe o un indicador secundario. `motion.holdActivity:ambient` conserva el foco
principal quieto; punctuated permite cambios secundarios breves. `still` deja
una pausa deliberada. Respetá movimiento reducido. La lectura decide la cadencia,
no un temporizador que obligue a cambiar algo cada segundo.

No fijar cuatro segundos por función, 120 BPM, un zoom universal o la misma escena
oscura para todos. Estas reglas orientan lanzamientos; no son defaults de cualquier
reel, storyboard o motion. El artículo aporta una guía, no una medición de retención
ni código que certifique su resultado.
