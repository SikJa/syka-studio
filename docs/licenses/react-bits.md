# React Bits Depth Carousel

Source: https://github.com/DavidHDev/react-bits and https://reactbits.dev/components/depth-carousel

The component in `apps/web/src/mirel-chat/features/agents/depth-carousel.tsx` and its CSS were adapted from the local reference in the component lab. Syka retains the original GSAP depth/tilt/blur/momentum/easing implementation and adapts sizing, Spanish controls, preview activation, keyboard access, scroll behavior and reduced motion.
