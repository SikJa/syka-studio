# House style

The fallback style: use it only when the brief, the project, or the user supplies no style
reference of their own. Any branding or direction they do specify wins, in whole or in part;
these references fill only the gaps it leaves.

## Read the relevant references

| Task | Read |
| --- | --- |
| Visual design or graphics | `design.md` |
| Copy or writing | `voice.md` |
| Video | `design.md`, `video.md`, `library.md` |
| Assets, components, or compositions | `library.md` and the reference for its medium |

When work spans multiple rows, use each relevant reference.

## Apply the style

1. Check `library.md` before creating a reusable asset, component, or composition.
2. Reuse the closest existing item and change its content or inputs.
3. Use relative paths to bundled assets instead of external file-share links.
4. Treat the values in these references as defaults. Depart from one when the subject, footage,
   or format calls for it, and keep the departure consistent across the piece.
