# HyperFrames caption adaptations

Source: heygen-com/hyperframes at commit 4371981b740d92f70e520cfbec34db68a1c93434,
the public caption-clip-wipe, caption-kinetic-slam, caption-weight-shift,
caption-neon-glow, caption-glitch-rgb, caption-gradient-fill,
caption-parallax-layers and caption-editorial-emphasis registry examples.

Upstream license: Apache License 2.0 (LICENSE.HyperFrames.txt).
https://github.com/heygen-com/hyperframes

Modified for Syka Studio on 2026-10-22: native Canvas caption decoders, local OFL
fonts, actual transcript timing, editable color slots and deterministic seeking.
These are adaptations, not pixel-identical HTML/GSAP embeds. No upstream CDN
scripts, demonstration transcript, texture assets or remote font files are used.
The surrounding runtime retains its existing MPL-2.0 license.
