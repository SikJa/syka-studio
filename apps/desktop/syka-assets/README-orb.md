# Orbe animado del README

`readme-orb.gif` es una exportación del orbe original de Syka, usando el componente `AgentIdentityOrb` en su variante `hero`, `AgentOrbCanvas` y el motor `thinking-orbs`. Conserva el preset 64, el estado `composing` y la velocidad 0.45. No contiene una reinterpretación generada del logo.

El GIF mide 128 × 128 píxeles, tiene 1.492 cuadros a 25 fps y repite el ciclo completo de 59,68 segundos. Se muestra a 116 × 116 en los tres README. La exportación conserva el fondo #111111 del editor.

El motor `thinking-orbs` conserva su [aviso MIT](LICENSE.thinking-orbs.txt). Los componentes de integración y la identidad de Syka mantienen las licencias y los créditos del repositorio.
